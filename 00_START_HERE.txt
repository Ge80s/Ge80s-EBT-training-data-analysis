💡 关键提示
═══════════════════════════════════════════════════════════════════════════════

【首次启动】
  • 需要 Node.js 18+ 和 Python 3.9+
  • 建议使用 VSCode 编辑器
  • 三个终端分别运行后端/前端/Electron

【开发技巧】
  • 前端有 HMR (热重载) - 改代码立即生效
  • 后端 --reload 模式自动重启
  • F12 DevTools 调试前端代码
  • 后端日志输出在终端

【常见问题】
  • npm install 失败: 运行 npm cache clean --force
  • 后端 8000 端口占用: 改用其他端口或关闭占用程序
  • 前端无法连接后端: 检查 CORS 和 API 地址
  • 更多问题: 查看 QUICK_START.md 常见问题部分
