🎯 立即可做的 4 个步骤 (20 分钟)
═══════════════════════════════════════════════════════════════════════════════

  📌 步骤 1️⃣: 创建项目目录 (5 分钟)
     ➜ python setup.py
     或手动创建目录结构

  📌 步骤 2️⃣: 复制源代码 (3 分钟)
     ➜ 将所有 .tsx/.ts/.py 文件复制到对应目录

  📌 步骤 3️⃣: 安装依赖 (10 分钟)
     ➜ cd EBT-Platform-React
     ➜ npm install
     ➜ cd backend && pip install -r requirements.txt

  📌 步骤 4️⃣: 启动应用 (2 分钟)
     ➜ 终端 1: cd backend && python main.py
     ➜ 终端 2: cd EBT-Platform-React && npm run dev:vite
     ➜ 终端 3: npm run dev:electron (可选)
     ➜ 打开: http://localhost:5173 ✨

🆘 快速故障排查
═══════════════════════════════════════════════════════════════════════════════

  问题                     解决方案
  ─────────────────────────────────────────────────────────────────────────
  npm install 失败         → npm cache clean --force && npm install
  后端无法启动             → 检查 Python 3.9+ 和依赖是否安装
  前端无法连接后端         → 确认后端运行在 http://localhost:8000
  文件上传出错             → 检查 Excel 编码 (UTF-8 或 GBK)

  👉 更多问题? 查看 QUICK_START.md 的「常见问题」部分
